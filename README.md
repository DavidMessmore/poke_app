# Poke App

A Pokémon team analysis application that allows users to build a team of up to six Pokémon and visualize its **type strengths and weaknesses**.

The project was inspired by the team analysis tools available on the **Marriland** website and was developed as a practical project to explore web application development and data-driven interfaces.

## Features

* Build a team with up to six Pokémon
* Analyze the team's type strengths and weaknesses
* Visualize type matchups in a clear and organized format
* Interactive team-building experience

## Future Improvements

Planned improvements include:

* Add support for different Pokémon generations (currently limited to Generation 9)
* Allow users to export and import teams
* Allow users to export the type matchup chart

## Purpose

This project is part of my software development portfolio and demonstrates practical experience in building interactive web applications, handling structured data, and presenting complex information in a user-friendly way.
